# 🦷 DentalEase – Dental Clinic Management System

## 📌 Project Overview
DentalEase is a web-based Dental Clinic Management System developed for **City Dental Surgery, Kurunegala**.  
It helps manage patient records, appointments, and clinic operations efficiently.

---

## 🎯 Objectives
- To digitalize patient record management
- To simplify appointment booking and tracking
- To improve clinic workflow and reduce manual errors

---

## 🛠️ Technologies Used
- Frontend: HTML, CSS, JavaScript, Blade (Laravel)
- Backend: Laravel (PHP Framework)
- Database: MySQL
- Tools: XAMPP, Git, GitHub

---

## 👥 User Roles
- **Admin**
  - Manage patients, appointments, and system
- **Receptionist**
  - Handle appointments and patient registration
- **Patient**
  - Register and book appointments

---

## ✨ Features
- Patient Registration & Management
- Appointment Booking System
- Appointment Status Tracking (Completed / Pending)
- Role-Based Access Control
- Search & Filter Patients/Appointments
- Responsive UI Design

---

## 🖥️ System Screens
- Home Page
- Dashboard
- Patient Management
- Appointment Management
- Contact & About Pages
